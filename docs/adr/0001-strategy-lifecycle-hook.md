# Strategy interface includes OnRequestComplete lifecycle hook

The `Strategy` interface exposes two methods: `Next(r *http.Request) (*Backend, error)` and `OnRequestComplete(b *Backend, duration time.Duration)`. We chose this over a minimal single-method interface because stateful strategies (Least Connections, Least Response Time) need to observe request completion — not just dispatch — to maintain accurate backend state. Placing the hook in the interface makes the contract explicit and keeps the proxy's responsibility clear: it calls both methods, always. Stateless strategies implement `OnRequestComplete` as a no-op. The alternative — letting stateful strategies self-track via middleware or goroutines — leaks responsibility and makes the proxy unaware of a lifecycle it is actually driving.
